# Project README

This project uses machine learning to predict the success of telemarketing campaigns.

## Requirements

* Python 3.8+
* pandas
* scikit-learn
* xgboost

## Usage

1. Install the required packages using `pip install -r requirements.txt`
2. Run the project using `python main.py`
3. The project will load the data, preprocess it, train the models, and evaluate their performance.
